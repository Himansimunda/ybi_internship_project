# Student Performance Prediction System

## Project Overview

This project predicts student performance using a Random Forest Classifier.

## Input Features

* Study Hours
* Attendance
* Previous Score
* Assignments Completed

## Output

The model predicts one of three performance classes:

* Low
* Medium
* High

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Joblib
* Matplotlib

## Project Files

* day23_student_performance_prediction_system.ipynb
* day23_student_performance_predictions.csv
* day23_student_performance_report.txt
* day23_student_performance_summary.csv

## Note

The model was trained on a small synthetic practice dataset.
Its predictions are for demonstration and are not a definitive
assessment of real student performance.
